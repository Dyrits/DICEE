# DICEE

A Las Vegas dice app built with Flutter, from The App Brewery's Complete Flutter Development Bootcamp.

## About The Project

A dice app: the die rolls at the press of a button, built with Flutter stateful widgets (`setState`). Companion project to The App Brewery's Complete Flutter Development Bootcamp. The project was created from scratch, replacing a previous outdated version.

### Built With

- Flutter
- Dart

## Getting Started

### Prerequisites

- The Flutter SDK

### Running

```sh
flutter run
```
